# input/

What you give the table. Your resume, the job posting, the assignment brief, the
rubric, the data, the reading list — anything the agents should look at.

Drop the files in and say so. You never paste them into a chat, and you never
paste them twice.

Nothing in here gets edited. Claude Code reads it, the advisors read it, and the
work comes out in `output/`.

The contents are gitignored — your resume is yours, not the repository's.
